# 资料文件恢复登记实验

本分支基于未上线的业务建议 v2 实验，不能合并或部署到真实工作区。处理来源集合之前，先提交绑定原 Job、资料来源摘要、文件摘要和存储键的登记；文件写入事务即使回滚，登记仍可定位同一潜在文件并允许原 Job 在重新核对岗位、原资料和摘要后重试。未提交的登记不能授权写入。登记仅存元数据，不存资料正文，不授权云发送。

隔离 PostgreSQL、合成来源和临时文件目录验证了事务异常、原任务重试、相同摘要并发共享、权限撤销和已存在的不安全目录/符号链接拒绝。崩溃是事务异常模拟，不是进程强杀；没有测试真实设备、成熟目标、正式界面或真实工作区。

该实现没有清理器，不删除共享文件；旧上传路径不参与同一把锁，无法安全证明共享文件无人使用。回滚后的明文文件仍可能存在，登记仅提供追踪，不能证明删除、保留期限或安全回收。路径检查只拒绝检查时已存在的不安全状态，无法阻止外部进程在检查之后替换目录或文件；现有通用 Evidence 读取路径也仍需安全改造。测试数据库标识只防止误用，不是生产安全边界。上线还须完成跨岗位离线授权、政策过期恢复、版本兼容、锁序、实际崩溃和生产存储隔离验证。

合并到期取消实验后：文件登记、处理及控制任务领取的候选路径增加原政策和当前用户会话的校验；仅 synthetic 资料/目标与专用 PostgreSQL 测试，不是正式后台授权。取消仅追加审计，不表示删除已登记文件或孤儿。仍未解决：源数据/审批的真实并发与物理文件清理；路径检查和文件写入之间的外部并发；先前版本 require_committed 在持任务锁时借第二连接可能超时（本实验已改为单连接核对，见下）；已领取控制 Job 在到期取消后仍可能显示 running（后续处理和新领取会拒绝），未提供可操作终态；取消回执写入后到调用方事务提交之间的会话自然过期尚未有提交前保护；完整旧版本写入口及真正离线授权仍不可用。不得部署、合并主线或视作已实现正式恢复。

单连接实验：在原事务锁定并核对登记 Job 和审计后，使用 PostgreSQL 的行事务标识与 pg_xact_status 检查两条记录均已提交；保存点释放但外层未提交、状态未知、不可用的数据库函数和事务回绕歧义均拒绝写文件。隔离 PG 回归覆盖单连接池、并发登记回滚、替代审计未提交和撤权。当前仅测试 PostgreSQL 17 专用测试集群；实际事务 ID 回绕、高龄被冻结行、低权限生产数据库角色、其他 PostgreSQL 版本及生产高并发尚未实证，状态不可核验会影响可用性。此实验不改变其他部署阻碍，仍不得合入主线或启用正式路由。
