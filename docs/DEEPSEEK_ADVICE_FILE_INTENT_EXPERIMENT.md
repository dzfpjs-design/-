# 资料文件恢复登记实验

本分支基于未上线的业务建议 v2 实验，不能合并或部署到真实工作区。处理来源集合之前，先提交绑定原 Job、资料来源摘要、文件摘要和存储键的登记；文件写入事务即使回滚，登记仍可定位同一潜在文件并允许原 Job 在重新核对岗位、原资料和摘要后重试。未提交的登记不能授权写入。登记仅存元数据，不存资料正文，不授权云发送。

隔离 PostgreSQL、合成来源和临时文件目录验证了事务异常、原任务重试、相同摘要并发共享、权限撤销和已存在的不安全目录/符号链接拒绝。崩溃是事务异常模拟，不是进程强杀；没有测试真实设备、成熟目标、正式界面或真实工作区。

该实现没有清理器，不删除共享文件；旧上传路径不参与同一把锁，无法安全证明共享文件无人使用。回滚后的明文文件仍可能存在，登记仅提供追踪，不能证明删除、保留期限或安全回收。路径检查只拒绝检查时已存在的不安全状态，无法阻止外部进程在检查之后替换目录或文件；现有通用 Evidence 读取路径也仍需安全改造。测试数据库标识只防止误用，不是生产安全边界。上线还须完成跨岗位离线授权、政策过期恢复、版本兼容、锁序、实际崩溃和生产存储隔离验证。

合并到期取消实验后：文件登记、处理及控制任务领取的候选路径增加原政策和当前用户会话的校验；仅 synthetic 资料/目标与专用 PostgreSQL 测试，不是正式后台授权。取消仅追加审计，不表示删除已登记文件或孤儿。仍未解决：源数据/审批的真实并发与物理文件清理；路径检查和文件写入之间的外部并发；require_committed 在持任务锁时再借第二数据库连接，池大小为 1 或连接耗尽时可能超时；已领取控制 Job 在到期取消后仍可能显示 running（后续处理和新领取会拒绝），未提供可操作终态；取消回执写入后到调用方事务提交之间的会话自然过期尚未有提交前保护；完整旧版本写入口及真正离线授权仍不可用。不得部署、合并主线或视作已实现正式恢复。

## 单连接协调器与唯一索引实验（不可上线）

本分支新增仅供专用隔离数据库使用的协调器：先在只读事务中读取已提交的资料登记和审计，结束事务并释放连接；之后新建独立处理事务，在原任务锁下重新比较原登记和审计的身份、版本、创建时间与摘要。该私有协调器不接受外部传入的 Session 或凭据，旧直接处理入口仍依赖第二条数据库连接。会话身份/事务对象绑定和预读证明只构成可信进程内部边界，不能抵御任意同进程 Python；它不能取代数据库约束、权限控制、真实资料审核或现场恢复验证。

**已实证绕过：** 在原审计行检查后、实际写文件前，一个不遵守任务锁的写者仍可在 READ COMMITTED 下插入第二条同 action、同对象审计，处理照常完成。现有正常登记写者遵守任务锁，但尚未证明所有其他写者/旧进程均遵守。禁止接入正式路由；文件路径被外部替换、孤儿文件安全清理、真实进程崩溃、离线岗位授权和旧写入口兼容仍未解决。隔离测试包含此绕过的复现，它通过表示风险被复现，不是安全验收。

仅在专属测试库验证过针对固定 action 的 `(workspace_id, object_id)` 部分唯一索引能拒绝并发重复审计；若已有重复数据，`CREATE UNIQUE INDEX CONCURRENTLY` 失败并可能留下 invalid 索引，历史记录不变。可审阅的生产迁移前置方案：只读盘点相同工作区和对象的重复凭据并保留待核，核对所有写者/权限和目标 PostgreSQL 版本；不能仅凭名称判断已安装，须验证模式、表、唯一性、字段顺序、谓词及 `indisvalid/indisready/indislive`；并发建索引失败时停止并核对 invalid 索引与正在运行的构建，不能静默跳过、自动重建或删除历史。须单独设计最小权限、无效索引处理、回滚和真实旧环境演练。本分支没有生产迁移，不得对真实库运行上述 DDL。

## 专用测试库的索引迁移协调器

`same_goal_advice_intent_index_migration_candidate_v2.rehearse()` 是仅供专用 PostgreSQL 17 测试集群的实验函数；没有 API、命令行或启动时注册，不可用于真实数据库。它严格核对测试集群身份，固定业务 action、两个字段和两个测试索引名；校验表结构、索引完整定义、唯一性及 valid/ready/live。它只读盘点该 action 的历史重复并拒绝迁移，不删除或修改任何历史及任何原索引。同名不同定义对象、进行中的索引构建、未知数据库版本均拒绝。构建失败后的 invalid 索引保留；若历史无重复且原构建不在运行，允许使用第二个固定名称重新构建，并显式返回保留的 invalid 索引。构建或进程中断后须核查索引状态，不能假设已成功。迁移锁竞争立即返回，连接锁等待和扫描/DDL 使用有界超时，返回连接池前恢复超时设置。

独立 PG 17 测试覆盖历史重复、同名无关索引、真实并发写/构建、进程取消后的 invalid 索引、备用名称恢复、跨工作区和其他 action 不受影响、连接池会话设置与 advisory 锁释放。未验证生产权限、其他 PostgreSQL 版本、低权限角色的进度可见性、外部 DDL 持续竞争或真实历史；写入路径也尚未将索引状态作为同事务前置条件。本实验不能代替正式迁移设计，也不授权在真实库运行 DDL。
