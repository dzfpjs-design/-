# 资料文件恢复登记实验：单连接方案已禁用

**禁止部署或接入正式路由。**此前单连接方案把 `pg_xact_status` 返回的子事务状态作为父事务已提交的证明。PostgreSQL 官方源码显示存在无法排除的子事务状态风险；独立 PostgreSQL 17 中对单层和 100 层常见保存点的测试尚未复现误判。此前 36 项测试不能证明这种方案安全，相关安全结论撤回。

当前 `require_committed` 无条件拒绝，故资料处理不会通过此候选写文件。原有预期成功的处理实验测试与此禁用状态不兼容，不能作为当前版本通过的证据。此前独立连接方案可以核对是否已提交，但在持任务锁时再次借连接，可能在连接池只有一个连接或耗尽时超时。

保守替代方案：先在取得任务锁之前完成并提交登记，再开始独立处理事务，对同一登记及审计重新加锁、核对绑定、权限与撤权。需要对跨事务竞争、崩溃恢复、用户会话到期、数据源变化、连接复用和未知结果完成验证后才能评估启用；此处尚未实现该方案。

其余阻碍仍未解除：文件写后回滚可能留下明文孤儿，缺少安全清理；路径检查与文件写入之间可能被外部进程替换；已领取的控制 Job 在到期取消后可能仍显示 running；取消审计到提交之间的会话到期、旧版本写入口兼容、离线岗位授权、真实成熟目标及生产部署均未完成。测试数据库标识仅防误操作，不是生产安全边界。
