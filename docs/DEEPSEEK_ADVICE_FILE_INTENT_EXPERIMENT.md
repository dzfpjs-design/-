# 资料文件恢复登记实验

本分支基于未上线的业务建议 v2 实验，不能合并或部署到真实工作区。处理来源集合之前，先提交绑定原 Job、资料来源摘要、文件摘要和存储键的登记；文件写入事务即使回滚，登记仍可定位同一潜在文件并允许原 Job 在重新核对岗位、原资料和摘要后重试。未提交的登记不能授权写入。登记仅存元数据，不存资料正文，不授权云发送。

隔离 PostgreSQL、合成来源和临时文件目录验证了事务异常、原任务重试、相同摘要并发共享、权限撤销和已存在的不安全目录/符号链接拒绝。崩溃是事务异常模拟，不是进程强杀；没有测试真实设备、成熟目标、正式界面或真实工作区。

该实现没有清理器，不删除共享文件；旧上传路径不参与同一把锁，无法安全证明共享文件无人使用。回滚后的明文文件仍可能存在，登记仅提供追踪，不能证明删除、保留期限或安全回收。路径检查只拒绝检查时已存在的不安全状态，无法阻止外部进程在检查之后替换目录或文件；现有通用 Evidence 读取路径也仍需安全改造。测试数据库标识只防止误用，不是生产安全边界。上线还须完成跨岗位离线授权、政策过期恢复、版本兼容、锁序、实际崩溃和生产存储隔离验证。
