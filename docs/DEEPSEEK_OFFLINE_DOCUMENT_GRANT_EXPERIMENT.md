# 业务建议离线资料岗位委托实验

仅供隔离数据库实验，尚未注册公开路由或常驻 worker，不能部署。此分支不授权云调用，不替代发起人逐模型核对和发送授权。

## 已验证的有限行为

真实登录的原资料岗位可对一个原 Plan/Job、政策和资料摘要签发持久授权；管理员或原资料岗位可以撤销，其他 operator 不可撤销。worker 根据已保存控制 Job 和数据库中的当前账号/工作区角色取得身份；用户注销后仍可领取并处理已存在的资料包。处理使用租约和提交前复核，保留原请求及唯一回执；旧租约、撤权、角色变化和来源摘要变化阻止继续。来源集合中新建共享文件的离线处理被拒绝。

常规隔离测试使用合成的已批准资料包来源及目标替身；异常和手动租期过期不等于真实进程崩溃。另通过独立 PostgreSQL 恢复全合成检查点，验证了真实审批代码生成的两级批准资料包和成熟目标：以正常 HTTP 登录依赖签发委托、注销后领取租约并完成资料包本地准备，重连检查回执及零云调用。测试中的委托路由仅存在于测试进程，策略与准备通过测试适配器调用；这个结果不等于正式 API、界面、常驻 worker 或真实生产资料已验证。没有验证真实人工角色、实际进程死亡及重启、最终业务建议或云端调用。

## 必须完成的接入与边界

- 接口应由现有登录、工作区和 CSRF 校验保护；资料岗位核对具体业务、原资料包、有限授权用途和政策到期时间后，再发起绑定原 Plan/Job 的授权。状态查询和同号重放需可刷新恢复；撤销要支持原资料岗位及管理员，并展示生效状态。
- 业务界面必须明确这是授权后台整理指定资料，不授权发送到云模型。待授权、授权生效、撤销、过期、账号权限变化、原资料变化、处理失败及已保存回执需可理解、可恢复，且不显示内部 ID 为主的操作界面。此分支没有这些界面或正式 API。
- 必须在正式源/审批写入侧证明资料变更与提交的锁序，完善跨工作区授权、全局命令编号与历史记录共存、控制 Job 注册与领取隔离、处理已准备后撤权与过期恢复。当前来源快照在提交前重读，但来源并发写入未整体加锁，不能声称完整竞态安全。
- 独立文件登记、共享文件清理与单连接提交证明尚未闭合；本实验只处理已有资料包，不应延伸为文件创建授权。先前以 `pg_xact_status` 单独证明外层事务提交的方案已禁用。
- 在合并或启用前，须完成真实人工角色、真实成熟目标和审批数据、实际进程 SIGKILL/重启、数据持久化与真实浏览器流程测试；旧通用 worker/API 混版与正式 8766 尚未验证。

## 合成检查点回归依赖

`tests/test_same_goal_advice_offline_real_checkpoint_pg.py` 依赖受保护的合成检查点和 `tests/synthetic_advice_fresh_checkpoint_restore.py`。仅允许独占的一次性 PostgreSQL、空云凭据、禁用外网和私有临时目录；恢复器不是生产备份恢复工具。测试按原合成记录恢复唯一 loopback origin 的测试白名单，不连接该设备。
