# 原始首答本地保全实验

本分支是专用隔离 PostgreSQL 实验，不含网络发送、正式接口或后台 worker。服务端原发送意图验证门默认拒绝；测试中明确替代的 gate 不是原发送证明，也不是发送授权。不得用本实验判断曾否发送或据此重发。

存储候选在一次事务中保存 BYTEA 原文、SHA-256 与独立 Audit 回执；唯一约束和表锁约束合作的测试写者。同原文和回执可重放，不同原文、残缺或不一致拒绝；未知状态明确不授权重发。表和回执可被有数据库写权限的非协作进程篡改，哈希不提供对恶意数据库所有者的真实性保证；不存在正式备份恢复保证。

恢复原始已付首答不能依赖当前会话、角色或有效租约。当前缺少无会话的固定服务端历史预留/intent 原件验证器；现有 read_reserved_test_only 依赖活动会话，不可当作历史验证器。必须核对独立原始 Start、预留账本、claim、intent、作用域和原始回执，并按固定协议核对发送时刻的原始授权，而不把历史结论当成新的发送许可。直到这一整链实现、竞态和撤权恢复测试通过，默认 gate 必须拒绝。

数据库测试只证明明确标注的合成 gate 下的本地保存与恢复，不证明真实模型响应、收费结算、真实授权、外发或生产可用。
