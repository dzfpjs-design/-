# 业务建议首答恢复入口：隔离验证边界

此候选默认关闭，并由专用测试 PostgreSQL 身份护栏限制；不得在真实工作区启用。管理员可在单个业务任务内发现原许可，查看时间与恢复状态，并将已完成、可认证的加密首答恢复入库和结算。接口依赖真实登录会话与 CSRF，重新读取暂存后在写入事务中复核并锁定当前管理员和会话。原请求不可重发，接口不包含派发路径。若首答已入库但结算中断，可仅从受保护的已保存原件结算，不要求临时暂存仍存在。

发现结果按调用关联分组并以稳定游标分页；许可字段损坏或只存在预留/发送意图的原记录显示待核，不能触发恢复。提交前以数据库当前时间再次核验会话有效性。对请求失败、响应格式无效及提供商未返回用量分别说明；现有同日汇总账本不能证明每笔均已计入，因此即使记录表看似一致，接口始终返回 `ledger_verified: false`，界面提示账本待核。

专用 PostgreSQL、本机假服务和构造的 Goal/来源测试覆盖：断线后保存与重登、恢复响应丢失后的状态刷新、跨工作区/岗位/CSRF 拒绝、文件读取后撤权、原件不完整以及幂等计量；React 在模拟 DOM 中验证提示和刷新。它不证明真实审批资料、真实 DeepSeek、物理设备、浏览器端到端或生产数据库重启。文件写入完成标记前的崩溃、磁盘故障、长期持久卷和独立密钥、暂存容量回收、旧记录/旧 worker 的全生命周期兼容、数据库迁移和事务锁争用仍未解决。用户业务结果仍需原流程核对。
