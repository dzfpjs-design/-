# 业务建议原子终态实验边界

本实验仅可在身份校验的专用 PostgreSQL 中建立独立测试表；没有路由、worker 或生产迁移。它在同一数据库事务中，对已完整保全的首答核验来源链、按已证明的供应商用量结算、写入关联终态及前后日账数据。重入只校验原回执，不重新发送或重复计量。提交前重新校验记录与日账，事务回滚不会留下终态。

没有可信供应商用量、无首答或链条不完整时保留原预留待核。旧调用若已结算但没有同事务终态，不能事后凭现有日汇总补造证明。失败响应即使有用量也仅标记失败，不表示产生业务建议。

本实验**不改变 Plan/Job 状态，也不使库存识别多条历史，不授权新的申请**。未知结果仍阻断；系统当前未实现同一业务的连续请求。记录及约束仍依赖测试库可信写入方，历史材料摘要不提供对任意恶意数据库写入方的独立认证；聚合日账后续变化也不能仅凭当前汇总证明每一条均已计入。需要生产级唯一约束、受限写入、可信逐笔账和迁移策略，并覆盖旧写方/崩溃/并发/自然日切、完整审批资料及真实界面后，才可考虑接入。

实现复用测试库全表门禁保护库存与终态写入；它可能影响其他工作区吞吐，尚未验证所有写方锁序，也不能作为生产锁方案。进程重建测试仅覆盖数据库连接重新建立，不代表 PostgreSQL 进程或操作系统重启恢复。
