# 离线资料整理授权：测试边界

默认关闭 `GA_OFFLINE_DOCUMENT_DELEGATION_ENABLED` 和 `GA_OFFLINE_DOCUMENT_WORKER_ENABLED`。API 使用既有工作区身份、会话与 CSRF 校验；即使打开开关，服务与 worker 仍拒绝除专用临时 PostgreSQL 外的数据库。不能用于正式环境或 8766，不能发送模型、操作设备或作为线上验收证据。

授权严格限定到原资料岗位、任务及已批准资料包；管理员或原资料岗位可以撤销。资料集合的后台写入尚未接通，不得从界面或 API 授权。worker 仅扫描专用 v2 资料控制任务，不领取旧版队列；失败保留原记录并显示安全错误类别。用户关闭页面不影响已提交授权。心跳使用进程唯一身份及原租约摘要，仅显示服务可用性，不延长租约或授权；正常停止标记离线，异常终止由短时心跳到期体现。

已提交的派发许可属于独立发送边界，撤销这里的资料整理授权不能保证撤回已经进入派发的请求。此提示不是授权云调用。正式 v2 资料准备入口、生产级恢复、真实设备与云模型调用、真实业务数据及用户浏览器体验仍需独立接入和验证。测试中的合成检查点不包含实际报告或设备资料。
