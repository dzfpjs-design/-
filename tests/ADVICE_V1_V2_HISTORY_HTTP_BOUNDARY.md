# 旧记录跨版本 HTTP 兼容实验边界

目标是在同任务已经有经过校验的 V2 预留或发送意图时，让用户继续读取 V1 历史并回放完全相同的原始申请或取消请求。实验由服务端发现单个预留并调用现有严格库存校验，HTTP 调用方不能指定或覆盖记录。新请求仍通过旧版严格门禁，不会因为读取旧记录获得新建或发送权。

`GA_V2_HISTORY_COMPAT_TEST_ENABLED` 默认关闭；启用后仍强制验证专用临时 PostgreSQL 身份。非专用数据库不能使用这个开关。发送许可、首答、结算、未知状态及旧进程并发写入尚未兼容，保持拒绝；不可据此部署到 8766。

隔离 PostgreSQL 和 ASGI HTTP 测试覆盖：原列表、详情、原请求查询、同号原文提交和取消回放、新编号及篡改正文拒绝、工作区和会话隔离、未知审计或账本篡改拒绝、重建登录会话后的读取、真实旧记录视图输出、未启用时拒绝及测试库护栏。原任务和模型数据是合成替身，`existing._task` 在该测试中被替代；没有验证真实成熟审批、实际浏览器、进程重启、生产数据迁移或业务效果。测试总是禁止真实云网络。

当前额度问题的隔离诊断以替身计数证明：政策发放配置在目标工具调用或步骤计数达到上限时仍会 409；没有更改旧 Goal。应单独修复此额度问题，保留每个申请的单次派发和重复发送保护。
